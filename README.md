
# 🧑‍💼 PeopleDesk – HR & Payroll Management System

A Streamlit application for managing employee HR operations, including:

- Employee management
- Attendance tracking
- Leave applications and approvals
- Monthly payroll management
- Payslip generation
- HR dashboard and summaries

## Technologies Used

- Python
- Streamlit
- SQLite

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Live Demo

Deployed using Streamlit Community Cloud.

## Project Purpose

Developed as part of a Python Developer Internship to apply Python programming, database management, and web application development skills.
